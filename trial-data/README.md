# trial-data · 试用数据目录

这个目录用于存放**真实试用者导出的快照文件**，不做任何数据伪造。

## 收集流程

1. 试用者在自己浏览器完成训练（至少完成前测 + 若干案例）。
2. 进入「我的学习报告」页底部，点击 **导出本次试用数据（JSON）**。
3. 试用者把生成的 `mingjian-trial-YYYYMMDD-HHmm.json` 发给你。
4. 把所有 json 放进本目录（文件名任意，不要放 `summary.md`）。

## 汇总

```bash
npm run trial:aggregate
```

脚本会：

- 读取本目录下所有 `*.json`，校验是否为明鉴试用快照；
- 输出样本数、完成情况、案例得分、四项维度、前后测、技能维度、案例难度观察；
- 把同样内容写入 `trial-data/summary.md`。

## 边界

- 目录为空时，脚本明确输出「**尚无用户测试数据**」，不会生成任何占位数字。
- 不做显著性检验；前后测变化只能表述为观察性结果，不能写成因果效果。
- 快照不含姓名、账号、设备标识与具体作答文本；但仍建议只保留试用者同意提供的数据。

也可以直接指定文件：`node scripts/aggregate-trial.mjs path/to/a.json path/to/b.json`
